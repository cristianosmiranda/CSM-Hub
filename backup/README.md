# CSM-Hub Backup

This directory contains a point-in-time copy of the CSM-Hub project.

The backup excludes the `backup/` directory itself to avoid recursive copies. Use `INSTALLATION.md` in the project root for the documented backup process and restore guidance.

See [MANIFEST.md](MANIFEST.md) for the snapshot contents and creation date.

Backup purpose:

- Preserve the current static homepage.
- Preserve the current Store and Blog module placeholders.
- Preserve the archive, images, README, license, and installation documentation.
- Provide a local recovery point before future platform work.
